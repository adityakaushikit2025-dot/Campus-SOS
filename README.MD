# Campus SOS

Campus SOS is a college emergency alert and response management system.

## Features

- Student login
- Emergency SOS button
- 5-second SOS cancellation
- Emergency type selection
- Campus location selection
- Emergency description
- Firebase Firestore database
- Real-time admin alerts
- Alert status management
- Pending, Responding and Resolved status
- Clear demo data

## Technologies Used

- HTML
- CSS
- JavaScript
- Firebase Firestore

## Project Modules

### Student Module
Students can log in and send an SOS alert by selecting the emergency type, campus location and description.

### Admin Module
Admin can view SOS alerts and update their status from Pending to Responding and Resolved.

## Database

Firebase Firestore is used to store SOS alert data.

## How to Run

1. Open the project in VS Code.
2. Start the project using Live Server.
3. Open the Campus SOS website.
4. Use the Student Dashboard to send an SOS alert.
5. Use the Admin Dashboard to manage alerts.

## Project Purpose

The purpose of Campus SOS is to provide a simple digital system for reporting and managing emergency situations inside a college campus.

## Note

This project is a college prototype. It does not directly contact police, ambulance or other emergency services.
